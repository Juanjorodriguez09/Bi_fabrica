# Decisiones del Coordinador

Registro de decisiones no triviales que tomó el `coordinador` al aprobar
planes — para no resolver dos veces distinto la misma pregunta de fondo.
Se consulta antes de decidir y se puede ir ampliando con el tiempo.

Este archivo es la versión liviana (texto versionado en git) de la base
de conocimiento — pensada para migrar a una base de datos real más
adelante, cuando esté disponible. Mientras tanto, cada entrada nueva:

```
## <fecha> — Issue #<n>: <resumen de la pregunta>

Decisión: <qué se resolvió y por qué>
```

Todavía sin entradas — el Coordinador recién se está probando por
primera vez.
